# TPad

TPad — це легкий та зручний текстовий редактор для Android, який дозволяє створювати, редагувати та зберігати текстові файли з різними розширеннями.

## Особливості
- Підтримка будь-яких текстових розширень (наприклад, `.txt`, `.log`, `.json`, тощо).
- Проста та інтуїтивно зрозуміла взаємодія.
- Відкрите програмне забезпечення, доступне під ліцензією GNU General Public License v3.

## Встановлення
1. Завантажте останню версію APK-файлу з [релізів](https://github.com/8a7l/TPad/releases).
2. Встановіть APK на свій пристрій Android.

> **Примітка:** Для встановлення додатка може знадобитися увімкнути дозвіл на встановлення з невідомих джерел у налаштуваннях вашого пристрою.
